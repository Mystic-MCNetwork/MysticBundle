我选择公开此脚本、仅仅是为了证明我写的脚本纯天然无添加无公害。<br>
Mystic Client 客户端仅在 Mystic Network 中以内部整合包的形式分发。<br><br>
在分发的安装包中，源代码并未加密，这就带来了两种审查代码的方式 ：<br><br>
1 - 审查我们在 Github 上托管的 MysticBundle 的代码；<br>
2 - 将 Mystic Client 安装包解压并审查代码。<br><br>
作为 Mystic Client 的开发者、我向使用客户端的用户们担保：MysticBundle / Mystic Client 中绝对不会参杂任何恶意代码。<br><br>
当然，随着 Mystic Client 添加的模组日益增多，开发者并不保证所在客户端内添加的模组不会含有恶意代码，仅能保证其都来自 Modrinth 或者 CurseForge。<br>
